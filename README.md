# Vouchpin（券钉簿）

骨架：券事件入湖 → 核销事实钉扎 → 过期/退回窗（后挖）→ 批次互证。

## 钉扎前过期：全局互斥策略

只贯彻一种：**到期自动作废**（另一策略「过期可核但默认排除钉扎」不启用）。

- 活动可配 `expire_window_hours`（0 = 无过期窗）。
- **过期扫描**（`POST /api/expire/scan`，钉扎前须可跑；seal 会在同一事务内自动先扫）：
  发放后超过过期窗且仍无核销的券码，写 `void` 事件入湖 + `coupon_voids` 作废标记，
  扫描运行写入 `expire_scans` 落库可查。扫描是改写闸，不是只读报表。
- **核销写入口**：已作废或已过期（按发放时刻+窗判定，不依赖扫描是否已跑）的券码 409 拒核；
  手工 void 同步落作废标记，已有核销事实的券禁止作废。
- **钉扎预览/集合**：open 集合排除作废券码；预览展示待作废数与已作废数。
- **批次快照**：记录钉前 `scan_id`、本次扫描新作废笔数、钉扎时刻作废总计。
- **核对**（`GET /api/expire/reconcile`）：未核过期核对（过期未核须已作废）、
  过期后核销核对（核销时刻不得晚于过期时刻）、作废入闸核对（作废券码不得出现在 open/sealed 事实）。

本地：
- API: `cd backend && python -m uvicorn app.main:app --port 10800`
- Web: `cd frontend && npm install && npm run dev`（5800）
